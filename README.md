# LudoTrip

Planejador de viagens com cara de jogo para qualquer viagem: uma cidade, várias cidades, vários países, road trip, cruzeiro ou trilha. Você monta o roteiro num mapa-tabuleiro, com fases, bonequinhos em pixel art e quests.

Para quem planeja:

- as noites por destino definem as datas;
- nada do que você planejou se perde quando muda algo;
- as reservas ficam sob controle.

A V2 nasce da v1 "Sakura Quest", feita para uma viagem ao Japão.

**Estado atual:** em construção (marco M3: mapa vivo e roteiro numa tela só). Teste em https://eduuf.github.io/LudoTrip/ (atualizado a cada push). Veja a [spec da V2](docs/superpowers/specs/2026-10-13-ludotrip-v2-design.md).
